# Scalable Signal Processing System

Production-style pipeline for large-scale time-series analytics.

## Features
- Synthetic large-scale signal generation
- Time & frequency domain feature extraction
- Scalable feature matrix building
- Machine learning training
- Model persistence
- Modular architecture

## Technologies
Python, NumPy, SciPy, Scikit-learn

## Run

pip install -r requirements.txt  
python -m src.main
